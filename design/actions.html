A dividend raises the multiplier, so each token represents slightly more stock. The pool holding that token does not know, and reprices only once someone arbitrages it.

Splits are neutral. The multiplier rises by the same factor the share price falls, so token value is unchanged and the pool never moves. Only dividends transfer value, and only by the dividend itself.

Honest note on this page

Seventeen actions in the chain's whole life is a thin stream, and most of them moved value by well under one percent. This page exists because the events are scheduled, readable in advance and nobody else surfaces them next to the pools they hit — not because it will fire every day. If you came here for a daily signal, the split board is the page you want.
